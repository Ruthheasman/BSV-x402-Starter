# BSV x402 Micropayment API — Replit Template + First Product

## The Big Idea

Build a TypeScript/Express template on Replit that lets any developer ship a paid API with BSV micropayments in under an hour. Then prove it works by wrapping one of your own services behind it.

John Calhoon built this in Rust on Cloudflare Workers. You're building the accessible version — your stack, your community, zero Rust knowledge required.

---

## Part 1: The Template — "BSV x402 Starter"

### What It Is

A one-click Replit template. Fork it, set your private key, define your endpoints and prices, deploy. You now have a production API that AI agents (Claude Code, etc.) can discover, authenticate against, pay, and consume — all autonomously.

### Tech Stack

- **Runtime:** Node.js 20+
- **Server:** Express + TypeScript
- **Auth:** `@bsv/auth-express-middleware` (BRC-103/104 mutual authentication)
- **Payments:** `@bsv/payment-express-middleware` (BRC-29/105 micropayments via HTTP 402)
- **Wallet:** `@bsv/sdk` (key derivation, transaction handling)
- **Build:** Vite (for any optional frontend dashboard)
- **Deployment:** Replit (primary), portable to any Node host

### Config-Driven Pricing

Developers define endpoints and prices in one file:

```typescript
// src/config.ts
export const endpoints = [
  // Tier 1: Micro — sub-$0.10
  {
    path: '/api/chef/recipe',
    method: 'POST',
    price: 1000,            // ~$0.06 — covers ~$0.02 LLM cost
    description: 'Generate a recipe from ingredients',
    handler: 'chefRecipe',
  },
  {
    path: '/api/suno/enhance',
    method: 'POST',
    price: 1000,            // ~$0.06 — covers ~$0.02 LLM cost
    description: 'Enhance a music generation prompt',
    handler: 'sunoEnhance',
  },
  // Tier 2: Standard — sub-$1.00
  {
    path: '/api/brand/analyse',
    method: 'POST',
    price: 5000,            // ~$0.30 — covers ~$0.10 LLM + scrape cost
    description: 'Extract brand identity from URL (text only)',
    handler: 'brandAnalyse',
  },
  {
    path: '/api/brand/content',
    method: 'POST',
    price: 6500,            // ~$0.40 — covers ~$0.12 LLM cost
    description: 'Generate platform-specific social posts from URL',
    handler: 'brandContent',
  },
  {
    path: '/api/startup/validate',
    method: 'POST',
    price: 8000,            // ~$0.50 — covers ~$0.15 heavy LLM cost
    description: 'Validate a business idea with SWOT, market sizing, and scoring',
    handler: 'startupValidate',
  },
  // Tier 3: Premium — $1-3
  {
    path: '/api/brand/full',
    method: 'POST',
    price: 33000,           // ~$2.00 — covers ~$0.65 (LLM + 5 images)
    description: 'Full brand kit: analysis, social content, 5 generated images',
    handler: 'brandFull',
  },
  {
    path: '/api/startup/full',
    method: 'POST',
    price: 20000,           // ~$1.25 — covers ~$0.40 heavy multi-section LLM
    description: 'Full startup report: validation, personas, business model, roadmap',
    handler: 'startupFull',
  },
  // Free
  {
    path: '/api/health',
    method: 'GET',
    price: 0,
    description: 'Health check',
    handler: 'healthCheck',
  },
] as const;
```

The payment middleware reads this config and sets prices per-route dynamically.

### Key Implementation Notes

1. **Auth must come before payment** — `@bsv/auth-express-middleware` sets `req.auth.identityKey`, which the payment middleware needs to know who's paying.

2. **Wallet setup** — The server needs a BSV wallet instance from `@bsv/sdk`. This handles key derivation, transaction verification, and `internalizeAction()` for accepting payments.

3. **Automatic refunds** — If your business logic fails after payment is accepted, issue a refund transaction back to the client. This is a differentiator over Coinbase's x402 (which has no refund mechanism).

4. **Nonce-based replay protection** — Each 402 response includes a unique `derivationPrefix`. The client must use this exact prefix when constructing the payment transaction. The wallet rejects duplicate prefixes.

## Part 2: The First Product — What To Wrap

### Evaluating Your Portfolio

Looking across 50+ apps, here's what maps well to a micropayment API. Criteria: standalone value per request, no ongoing state needed, viable unit economics after AI/image generation costs.

**Cost Reality Check:** Every product that calls an LLM or generates images has real per-request costs. Gemini LLM calls run ~$0.01–0.10 depending on model and tokens. Image generation runs ~$0.10 per image. Pricing must cover costs with margin (target 3x) or you're running a charity.

|-----|--------------|-----------|------------|------------|-------|
| **AI Chef Assistant** | **Excellent** | ~$0.02 (LLM only) | **$0.06** | Low | Ingredients in → recipe out. Cheapest to run, best template demo. |
| **Suno Sidekick** | **Good** | ~$0.02 (LLM only) | **$0.06** | Low | Prompt enhancement. Cheap, fast, niche but useful. |
| **StartupScout (text)** | **Excellent** | ~$0.15 (heavy LLM) | **$0.50** | Medium | Business idea → validation report. High perceived value. |

### Launch Strategy: Tiered by Cost

The smart move is to launch multiple products at different price points behind the same x402 server. This proves the template works across the spectrum — from sub-penny to a couple of dollars.

**Tier 1 — "The Demo" (near-zero cost, proves micropayments work):**
AI Chef Assistant and/or Suno Sidekick at $0.06/request. These are the "Stripe literally cannot process this" products. Perfect for the X thread.

**Tier 2 — "The Workhorse" (moderate cost, real utility):**
BrandCaster text analysis and StartupScout text report at $0.30–0.50/request. Still well under a dollar. AI agents would happily pay this.

**Tier 3 — "The Premium" (higher cost, full deliverable):**
BrandCaster full kit (with 5 images) at $2.00 and StartupScout full report at $1.25. These compete with $29/month SaaS subscriptions on a pay-per-use basis.

### Recommendation: Launch Multi-Product, Lead with AI Chef

**Why AI Chef Assistant should be your first endpoint:**

1. **Lowest cost per request (~$0.02)** — The margin is massive. At $0.06 you're making 3x with room to spare. No image generation costs eating your profit.

2. **Proves the micropayment thesis viscerally** — "A recipe for 6 cents" is the kind of number that makes Stripe's $0.30 minimum fee look absurd. This is the headline for your X thread.

3. **Universal appeal** — Everyone eats. AI agents, developers, end users — nobody needs convincing that a recipe generator is useful.

4. **Dead simple API shape** — Ingredients in, recipe out. Fast response time, no image pipeline, no scraping. The perfect v1.

5. **Already built** — The core logic exists in your AI Chef Assistant app.

**Then immediately add BrandCaster as the premium tier:**

BrandCaster is the *better* product, but it's a harder first demo because the costs are higher and the image generation adds latency. Launch it as Tier 2/3 once the plumbing is proven with Chef.

**Why BrandCaster still matters:**

1. **You actually use it yourself** — strongest possible signal.
2. **Perfect for AI agents** — "Analyse my competitor's brand" is a natural Claude Code workflow.
3. **Tiered pricing proves flexibility** — Text-only at $0.30, full kit with 5 images at $2.00. Shows the template handles both sub-dollar and multi-dollar transactions.
4. **Dual revenue** — Keep the web app for direct users. The API serves agents and developers.

### Pricing Philosophy

The three tiers serve different purposes:

**Tier 1** proves the concept. These are the "holy shit, I just paid 6 cents for a recipe via Bitcoin" moments. They make the X thread. They get the Replit community interested.

**Tier 2** pays the bills. $0.30–0.50 per request with 3x margins is a real business at volume. An AI agent running 100 brand analyses a day generates $30/day in revenue at ~$20/day profit.

**Tier 3** shows the ceiling. Full BrandCaster with 5 generated images at $2.00 competes with $29/month SaaS tools on a per-use basis — and wins for anyone who doesn't need it daily.

## Risks + Mitigations

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| `@bsv/payment-express-middleware` has bugs or missing features | Medium | It's 6 stars, low usage. Read the source. Fall back to implementing BRC-105 directly if needed — the spec is clear. |
| BSV SDK has native compilation issues on Replit | Medium | Test on Day 1 before committing. If blocked, use WASM builds or pure-JS fallbacks. |
| No one has a BSV wallet to test with | High (outside BSV community) | Include a test client script that creates a throwaway wallet and sends test payments. Make the onboarding frictionless. |
| Teranode transition breaks wallet reliability | Medium | You've dealt with this before. Use established wallet infrastructure, not bleeding-edge. |
| Limited demand from non-BSV developers | High initially | This is a long play. The template proves the concept. Mainstream adoption follows infrastructure, not the other way around. |
| AI generation costs higher than estimated | Medium | Build cost logging into every endpoint from day 1. Track actual Gemini/image costs per request. Adjust pricing within the first week based on real data. 3x margin gives buffer. |
| Image generation costs spike or provider changes pricing | Medium | Abstract image generation behind a service interface. Can swap providers (Gemini → other) without changing API contracts. Price the full-image tier conservatively. |
| BSV/USD exchange rate volatility affects sat pricing | Low-Medium | Price endpoints in USD equivalent, calculate sats dynamically at request time. Or reprice weekly. At these amounts, small fluctuations don't matter much. |
